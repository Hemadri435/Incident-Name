Azure AD App Registration (One-time setup)

Why is this needed?Microsoft Graph API requires an Azure AD App Registration to authenticate users and obtain permission to read/write SharePoint data.
1Go to portal.azure.com → Azure Active Directory → App registrations → New registration
2Name it Claims Tracker App, select Accounts in this org only, Redirect URI: Single-page application → http://localhost/ or your hosted URL
3After creating, copy the Application (client) ID and Directory (tenant) ID
4Go to API Permissions → Add permission → Microsoft Graph → Delegated → add: Sites.ReadWrite.All, User.Read
5Click Grant admin consent for your organisation

Graph API Endpoints Used

GET /sites/{siteId}/lists/{listId}/items?expand=fields
→ Fetch all incident records
POST /sites/{siteId}/lists/{listId}/items
→ Create new incident
PATCH /sites/{siteId}/lists/{listId}/items/{itemId}/fields
→ Update existing incident
DELETE /sites/{siteId}/lists/{listId}/items/{itemId}
→ Delete incident
GET /sites/{siteId}/lists/{listId}/items?$filter=fields/Estimated_Date eq '{today}'
→ Due date check for email notifications
